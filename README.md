# landing-page — «Черновик»

Простой лендинг сервиса «Черновик» — приложения для студентов, которое хранит конспекты по предметам и напоминает о дедлайнах сдачи работ.

Проект выполнен в рамках практического занятия № 5 «Настройка работы системы контроля версий» (Git, GitHub, GitHub Pages).

## Технологии

- HTML5
- CSS3 (адаптивная вёрстка, без фреймворков)
- Google Fonts (Caveat, Work Sans)

## Структура проекта

```
landing-page/
├── index.html   — разметка страницы
├── style.css    — стили
└── README.md    — описание проекта
```
